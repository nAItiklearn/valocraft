Important notes

  • Download the game archive for your platform — not GitHub’s “Source code (zip)”.
  • Extract the archive completely and launch from inside the extracted folder. Do not run the game from inside the zip.
  • All builds are portable: saves and settings live in userdata/ beside the binary.
  • The dedicated server (ValocraftServer) is included in every archive.
  • Verify downloads with SHA256SUMS.txt on the release page.

Install instructions

Windows

  1. Download the .zip and choose Keep if the browser warns.
  2. Right-click → Extract All to e.g. C:\Games\Valocraft.
  3. Open the folder and double-click run.bat.
  4. SmartScreen: More info → Run anyway.

macOS

  1. Open the .dmg and drag Valocraft to Applications.
  2. First launch: right-click the app → Open → confirm.
  3. If macOS says the app is damaged: xattr -dr com.apple.quarantine /Applications/Valocraft.app

Linux

  1. tar -xzf Valocraft-v*-linux-x86_64.tar.gz
  2. cd Valocraft-v*-linux-x86_64
  3. ./run.sh

First launch automatically creates a world and boots into offline singleplayer — no account needed. Full details in the Game Guide.

Build from source

Requirements: Rust (pinned toolchain), Git LFS, CMake, Ninja, and platform build tools.

git clone https://github.com/nAItiklearn/valocraft.git
cd valocraft
git lfs install && git lfs pull
cargo build --release --bin veloren-voxygen

Full build instructions: RUNNING.md · CODEBASE_INDEX.md
