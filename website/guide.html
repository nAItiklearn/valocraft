Game Guide

Everything you need to start playing Valocraft — offline-first, no account required.

Getting started

  1. Download and extract the archive for your platform.
  2. Launch run.bat (Windows), Valocraft.app (macOS), or ./run.sh (Linux).
  3. The game boots straight into an offline singleplayer world as the profile Player. A world and character are created automatically on first launch.

No account, internet connection, or server setup is required for local play.

Emberwatch contracts

Press U to open the Emberwatch Field Journal. Near the Hearthpost Ember Board you can accept three kinds of contracts:

  • Survey — travel to a marked site and scout it.
  • Bounty — hunt down a marked target.
  • Courier — carry word to a relay and return.

Objectives are tracked on the HUD and marked on the map and minimap. Completed contracts award coins and Emberwatch standing. After three contracts, return to the board to light the Emberwatch Beacon for a bonus reward. Standing, completion count, and the beacon are saved in your profile.

Exploration

  • Biomes: forests, grasslands, deserts, mountains, snowfields, oceans, rivers, lakes, and caves.
  • Points of interest: towns, villages, dungeons, ruins, camps, and landmarks.
  • Dynamic day/night cycle, weather, and a full world map (M) with markers.
  • Climb, swim, glide (Ctrl), and tame mounts (F) to travel faster.

Combat

  • Melee: swords, axes, hammers, and shields. Block, dodge, roll, and use weapon abilities.
  • Ranged: bows and thrown weapons.
  • Magic: staffs and spells.
  • Enemies: wildlife, hostile factions, monsters, and dungeon bosses.

Early-game combat is intentionally forgiving: players take reduced incoming damage while they learn the ropes. A small FPS/frame-time readout sits at the top of the screen so you can gauge performance.

Character & progression

  • Multiple playable races with appearance customization.
  • Earn XP, level up, and unlock skills.
  • Equip weapons, armor, bags, gliders, lanterns, and modular gear.
  • Find loot and improve item quality to tailor your build.

Crafting, cooking & trading

  • Craft at workbenches and specialized crafting stations.
  • Make weapons, armor, tools, gliders, lanterns, and bags.
  • Cook food and brew potions.
  • Trade with NPC merchants using in-game currency; grow your recipe book as you discover recipes.

Multiplayer & dedicated servers

Valocraft has no central account service. Every server is independent and manages its own players:

  • Start the included dedicated server (run-server.bat / run-server.sh, or ValocraftServer). The default game port is 14004.
  • Connect from the client’s multiplayer menu using the server’s address. The first client launch auto-boots into singleplayer; log out to the main menu to reach the server browser.
  • Most servers need no account: pick a username and play.
  • Servers with authentication run their own self-hosted auth service; the server owner tells you where to register. You only trust the auth endpoints you choose in Settings → Network.

Running your own server

  1. Every desktop download includes ValocraftServer.
  2. Launch it once to generate configuration and saves under userdata/server/.
  3. Local and private servers run without remote authentication out of the box.
  4. To let friends join over the internet, forward port 14004 (TCP/UDP) on your router/firewall and share your public address.
  5. Server-side plugins and game rules are configurable in the server settings files.

Where saves live

  • Windows / Linux (release): userdata/ beside the game binary.
  • macOS: ~/Library/Application Support/Valocraft/userdata/

You can move the whole folder to another computer — the game is portable.

Troubleshooting

  • Assets missing: extract the full archive; the game needs the assets/ folder next to it.
  • Windows SmartScreen: More info → Run anyway (build is not code-signed yet).
  • Missing VCRUNTIME140.dll: install the Microsoft Visual C++ Redistributable (x64).
  • macOS “app is damaged”: xattr -dr com.apple.quarantine /Applications/Valocraft.app, then right-click → Open.
  • No rendering device: update your GPU drivers; a Vulkan, DirectX 12, Metal, or OpenGL-capable GPU is required.
  • Logs: see userdata/voxygen/logs/.

Status & roadmap

Valocraft is in alpha: systems may change, saves may be incompatible between versions, and bugs are expected. On the roadmap: survival-style block building, more dungeons and quests, continued balance, and Windows-first packaging improvements.
